Event Bus & Dashboard Sync

How It Works

  1. Agent completes an action ΓåÆ writes to WorkLedger.
  2. Agent emits event to AgentEventLog with type + target.
  3. Dashboard listeners poll for new events matching user's role.
  4. UI updates in real-time without full page refresh.
  5. Orchestrator watches for stuck/failed events and escalates.

Governance Rules

  1. No agent self-approval: Every agent output requires cross-agent or human validation.
  2. Full audit trail: Every action logged with correlation ID across the lifecycle.
  3. Sensitive ops require humans: Deploy, rollback, role changes need explicit approval.
  4. Token budgets enforced: Per-agent daily LLM token limits prevent runaway costs.
  5. Prompt changes shadow-tested: New prompts evaluated against baseline before production.
