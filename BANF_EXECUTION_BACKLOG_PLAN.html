Sprint Plan (12 Weeks)

Sprint 1: Stabilize Security Core

  • Migrate secrets to Wix Secrets Manager.
  • Remove privileged bypass patterns.
  • Normalize auth/session verification.

Sprint 2: Control Plane Hardening

  • Implement endpoint permission matrix.
  • Add idempotency keys for payment/check-in.
  • Create security audit event schema/dashboard.

Sprint 3: Modularization Start + Workflow Gaps

  • Introduce compatibility router scaffold.
  • Implement membership exception lifecycle.
  • Harden CORS and add endpoint throttling.

Sprint 4: Performance + Event Completeness

  • Two-stage RAG retrieval optimization.
  • Waitlist and auto-promotion rules.
  • KPI dictionary + traceability gate v1.

Sprint 5: Scale + AI Guardrails

  • Materialized summaries for reporting.
  • AI moderation/redaction pipeline.
  • Scheduled job orchestration for heavy tasks.

Sprint 6: Reliability Readiness

  • Incident runbooks + break-glass controls.
  • Game-day drill with postmortem closure.
  • Modularization cutover checkpoint.
